Qué puedes hacer

Listas y progreso
Organiza varias listas, cambia el estado de tus juegos y guarda notas, tareas y objetivos personales.
Steam
Conecta tu cuenta para importar juegos y consultar logros. La sincronización se realiza al abrir la app y periódicamente.
Amigos de Checkpoint
Comparte tus avances con amigos mediante tu código de Checkpoint. Puedes mantener juegos privados.
Aplicación de Windows
Usa una ventana translúcida, el modo miniatura y la detección de juegos para consultar los logros pendientes.

Tus datos en el navegador

La biblioteca se guarda en este navegador. Puedes importar y exportar copias JSON. La biblioteca privada no se sincroniza automáticamente entre la web y Windows.
