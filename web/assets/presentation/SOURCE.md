Artwork rights remain with the respective owners. The images are not Creative Commons assets or AI-generated imagery. Hollow Knight and Hades use the existing local fixtures in `scripts/fixtures/covers`; Portal 2 retains the existing public cover. The interface surrounding them is rendered as HTML/CSS using Checkpoint's shared fonts, logo and theme tokens. The displayed collection and progress are examples, not user data.
