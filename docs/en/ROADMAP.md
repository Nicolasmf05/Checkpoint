# Roadmap

**English** · [Español](../ROADMAP.md)

## Included

- **0.3:** translucent widget, three virtualized views, drag/keyboard ordering, deletion recovery, complete cover backups, themes, saved bounds, local SQLite, states/tasks/goals, Steam OpenID service, tray/shortcuts and verified x64 packages.
- **0.4:** independent Checkpoint accounts, accepted friendships/requests/blocks, optional game/progress publication, durable account-bound outbox, conflicts and private cover access through Supabase. Username/password without email confirmation. Real two-account validation pending.
- **0.5:** English/Spanish UI selector, saved language, both-language documentation and captures, translation/privacy tests.

## Collection experience

Named priorities, optional new-achievement notifications, configurable text size, screen-reader validation, mixed-DPI monitor and ARM64 testing.

## Public distribution

Host/validate Steam with a real account; complete operator identity/contact/country and review hosting logs. Test install/update/uninstall on a clean machine. Sign artifacts and verify update packages. Add shared session/cache persistence if Steam hosting scales. Validate two real Checkpoint accounts and private Storage operations. Add account recovery/deletion, avatar UI and retention cleanup.

## Optional

Monthly statistics, next-game picker, play sessions, cross-PC private-library sync and more catalogs. Deadlines remain optional.

## Microsoft Store preparation

Unsigned MSIX preview packaging, icons, SDK/payload validation and bilingual submission guidance are implemented. Partner Center identity, installed-package/data/startup tests, Windows App Certification Kit and Store submission remain pending. See [Store preparation](MICROSOFT-STORE.md).
