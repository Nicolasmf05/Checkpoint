# Configurable shortcuts

**English** · [Español](../SHORTCUTS.md)

Open **Settings → Configure shortcuts**, or **Keyboard shortcuts → Configure shortcuts**. Focus a field and press your combination. **Save** validates and applies changes; **Cancel** keeps the previous settings. **Restore defaults** prepares the original bindings: click Save to apply them.

Configure add, search, restore a deleted game, change view, hide, help, edit in Miniature, list navigation and ordering. Windows also supports configuring the global show/hide shortcut. Duplicate combinations are rejected. If Windows rejects a new global binding occupied by another application, the previous configuration is retained.

Letters and digits require Ctrl or Alt to preserve ordinary typing. Shift, F1–F24, up/down arrows, Home, End, PageUp, PageDown and Enter are supported. Tab still moves focus; Escape closes help, menus and dialogs; Space activates controls and opens the selected Miniature game menu. Escape and Space cannot be reassigned to other actions. Widget undo does not replace text-field undo.

Preferences persist in SQLite on Windows and IndexedDB on the web. Hints and help display your bindings. Older settings keep the default shortcuts. Browsers or the operating system may reserve some combinations; the web has no global shortcut.
