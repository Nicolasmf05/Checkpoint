# Themes

**English** · [Español](../THEMES.md)

Settings → Theme includes 22 palettes: the original eight plus all fourteen new themes. Preview applies to the collection, dialogs, achievements, friends, notices and Miniature; Save retains it, Cancel restores the previous theme.

The mixed second table is interpreted as a set of main colors: Blue + White, Emerald + Neutral, Coral/Pink + Cream and Indigo + Soft Gray use light backgrounds. Black + White uses cyan as its unspecified accent. Panel, field, border and muted-text colors are derived from each palette; secondary colors that are white are used as neutral palette colors rather than white text on a light background. Names follow the selected language. Existing selections and theme IDs remain valid.
