# Atajos configurables

[English](en/SHORTCUTS.md) · **Español**

Abre **Ajustes → Configurar atajos**, o **Atajos de teclado → Configurar atajos**. Selecciona un campo y pulsa la combinación que quieras. **Guardar** valida y aplica los cambios; **Cancelar** conserva la configuración anterior. **Restablecer predeterminados** prepara los originales: pulsa Guardar para aplicarlos.

Puedes cambiar añadir, buscar, recuperar un juego eliminado, cambiar vista, ocultar, abrir ayuda, editar en Miniatura, navegar por la lista y reordenar. En Windows también puedes cambiar el atajo global para mostrar u ocultar Checkpoint desde otra aplicación. Las combinaciones repetidas no se guardan. Si Windows rechaza un nuevo atajo global ocupado, se conserva la configuración anterior.

Las letras y números requieren Ctrl o Alt para no interferir con la escritura. Se admiten Shift, F1–F24, flechas arriba/abajo, Inicio, Fin, RePág, AvPág e Intro. Tab sigue moviendo el foco; Escape cierra ayuda, menús y cuadros; Espacio activa controles y abre el menú de un juego en Miniatura. No se asignan Escape ni Espacio a otras acciones. Deshacer del widget no sustituye al del campo de texto.

Las preferencias persisten en SQLite en Windows y en IndexedDB en la web. Los rótulos y la ayuda muestran tus combinaciones. Los atajos predeterminados siguen funcionando al actualizar desde una versión anterior. En el navegador, algunos atajos pueden estar reservados por el propio navegador o el sistema; la web no tiene atajo global.
