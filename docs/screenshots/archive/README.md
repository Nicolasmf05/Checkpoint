# Archivo histórico de capturas / Historical screenshot archive

Estas imágenes se conservan para documentar versiones anteriores; **no muestran el diseño actual de Checkpoint**. La [galería actual](../../SCREENSHOTS.md) utiliza capturas renovadas de Chromium y WebView2.

Los PNG `wpf/` proceden del renderer WPF anterior (0.6.x). Los dos PNG `pre-unified-css/` muestran una presentación de logros sustituida, cuyo productor ya no existe en los tests actuales. Se mantienen sus píxeles originales y se añade únicamente procedencia embebida. La fecha exacta de cada captura no quedó registrada.

These images are retained as historical evidence, not as the current product interface. The [current English gallery](../../en/SCREENSHOTS.md) uses refreshed Chromium and WebView2 captures. WPF examples and superseded achievement views retain their original pixels; only embedded provenance is added.
